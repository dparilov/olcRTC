Final commit includes DNS parameter fix (was misrouted as socksPass in mobile binding).

## Features

- Multi-tenant bootstrap v2 with Yandex SSO registration
- Android client with VPN tunnel (tun2socks + SOCKS5 via WebRTC DataChannel)
- Per-app VPN routing (allowlist mode, user-configurable)
- Yandex Disk log upload (60s interval, auto-cleanup)
- Let's Encrypt HTTPS endpoint (`ru-03.komarovo.online:8090`)
- Komarovo VPN egress (external IP: `149.33.36.216`)
- Encrypted SharedPreferences for secrets (OAuth token, master secret)

## Rollback procedure

### Server
```bash
ln -sfn /opt/olcrtc-releases/2.0.0 /opt/olcrtc-releases/current
killall olcrtc-bootstrap-v2 olcrtc
cp /opt/olcrtc-releases/current/olcrtc-bootstrap /opt/olcrtc-bootstrap-v2
cp /opt/olcrtc-releases/current/olcrtc /opt/olcrtc
# Restart bootstrap with standard flags
nohup /opt/olcrtc-bootstrap-v2 -port 8091 -port-start 2080 -port-end 2179 \
  -state-dir /opt/olcrtc-state-v2 -binary /opt/olcrtc -dns 1.1.1.1:53 \
  -encrypt-key "olcrtc-secrets-2026" > /opt/olcrtc-bootstrap-v2.log 2>&1 &
```

### Android
Reinstall `client-v2.0.0.apk` from Yandex Disk. Local data (tenant, secrets, settings) is preserved on reinstall with same package/signing.
